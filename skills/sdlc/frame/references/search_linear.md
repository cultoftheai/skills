# Search Linear issues

Use the Linear tool that is connected in the session, with the key terms as its query.

If no Linear tool is connected, ask the person to connect one, and search after they have. With `--auto`, go to step 10 and name the missing tool.

- An issue is open when its state type is not `completed` or `canceled`.
- Report each match by its identifier, such as `ENG-12`, its title and its state.
